# Fresh implementation with on-demand historical reference

Start `go-ios-vm` as a fresh Go project with an IPSW/firmware inspection tool suite and a macOS Hypervisor.framework VM runner. Tools are the initial focus, and Python is acceptable for supporting work.

The previous effort repeatedly diverted into preserving reports and developing infrastructure without delivering a usable runner or the intended tools. The user rejected a migration package or inherited evidence archive. Historical findings may be consulted when a specific question requires them; legacy code, assets, reports, and architecture are not imported as a baseline. This trades automatic reuse for a smaller, independently justified project. It does not authorize deletion of the old repository.
